# Vault

Your second brain. Write anything into `Inbox/` (from Obsidian on your phone or computer: it syncs through Syncthing) and the server's sorting job files it within half an hour, or within a minute if the note contains `#now`.

- Tasks and events go to your calendar if one is configured, otherwise to notes.
- People, documents, journal entries, ideas get their own notes; the original is archived in `Archive/Inbox/` with a link to everything it produced.
- An idea about the server itself is also proposed as an issue in the tracker: it becomes work only when you approve it there.
- When the brain isn't sure, it leaves the note in `Inbox/` with a `## Question from the brain`: answer below it.

The glossary of kinds, tags and folders is [[Ontology]]. The sorting rules live on the server, not here, so nothing in the vault can change them.
