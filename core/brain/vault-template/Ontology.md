# Ontology

The kinds of items, their tags, and where they go. The sorting job keeps this page up to date.

## Kinds (tags)
- #doc — a personal document (ID, contract, bill): a card in `Areas/Documents/`, the file in `Attachments/Documents/`.
- #task — something to do: your calendar's task list, or a note with `- [ ]`.
- #event — something with a date and time: your calendar, or a note.
- #note — a note on a topic: `Resources/<topic>/` or `Notes/`.
- #journal — a diary entry: `Daily/YYYY-MM-DD.md`.
- #person — someone: `Areas/People/First Last.md`.
- #idea — an idea: `Projects/<Project>/`, or `Projects/Ideas/` when it belongs to no project.
- #now — not a kind: sort this right away.

## Folders
- `Inbox/` — where you write. `Archive/Inbox/YYYY-MM/` — originals after sorting.
- `Projects/`, `Areas/`, `Resources/`, `Notes/`, `Daily/`, `Attachments/`, `Templates/`.

## Fields
- `origin` (frontmatter) — the archived item a note came from.

## Names
File and folder names never contain `: * ? " < > | \ / # ^ [ ]` (phones can't store some, Obsidian links break on others).
