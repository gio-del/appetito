Mail

Le mail che inoltri al tuo indirizzo con +edge finiscono nell'Inbox del second brain, e il server può scriverti. Passa da un piccolo script nel tuo account Google: il server vede solo le mail mandate a quell'indirizzo e può scrivere solo a te.

1. Copia lo script

Contiene un segreto che conosce solo il server: non incollarlo in chat o altrove.

Mostra lo script

2. Pubblicalo nel tuo account Google

  1. Apri script.google.com → Nuovo progetto. Se dal telefono l'editor non si apre bene: menu ⋮ di Chrome → Sito desktop.
  2. Tocca Progetto senza titolo e chiamalo edge-mail.
  3. In Codice.gs cancella tutto, incolla lo script e salva (icona del dischetto).
  4. Esegui il deployment → Nuovo deployment → ingranaggio accanto a «Seleziona tipo» → App web.
  5. Esegui come: Me. Chi ha accesso: Chiunque. Poi Esegui il deployment.
  6. Autorizza l'accesso → il tuo account → «Google non ha verificato questa app» → Avanzate → Vai a edge-mail (non sicura) → Consenti. È normale: l'app è tua.
  7. Copia l'URL dell'app web (finisce con /exec) e incollalo qui sotto.

2. Pubblica la nuova versione

  1. Apri script.google.com → progetto edge-mail. Se dal telefono l'editor non si apre bene: menu ⋮ di Chrome → Sito desktop.
  2. In Codice.gs cancella tutto, incolla lo script e salva (icona del dischetto).
  3. Esegui il deployment → Gestisci deployment → matita Modifica → Versione: Nuova versione → Esegui il deployment. Non fare un «Nuovo deployment»: l'indirizzo cambierebbe.
  4. Se chiede di autorizzare: Autorizza l'accesso → il tuo account → Avanzate → Vai a edge-mail (non sicura) → Consenti.
  5. Fatto: l'indirizzo resta lo stesso e non va salvato di nuovo. Entro 2 minuti questa pagina torna a «Collegato».
